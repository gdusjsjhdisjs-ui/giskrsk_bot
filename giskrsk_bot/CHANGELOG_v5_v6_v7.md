# v7 — Единое мини-приложение (хаб)

## Что нового

### 📱 Хаб с тремя вкладками (webapp/index.html полностью переписан)
- **🗺 Карта** — всё из v6 (MapLibre, поиск, слои, подложки) + в карточке зоны кнопка «🛒 Купить данные этого района» → вкладка Магазин.
- **🛒 Магазин** — 4 тарифа подписки (сетка карточек, бейдж «Хит»), карточка пробного дня, 5 товаров с фото/ценой/описанием. Кнопка «Купить» открывает бота и СРАЗУ создаёт заказ с копеечным кодом и реквизитами.
- **👤 Профиль** — имя/аватар из Telegram, меню: мой доступ, пригласить друга (+7 дней), пробный день, поддержка, блок «Как это работает».
- Нижняя навигация, тёмная/светлая тема по Telegram, хаптика.

### 🤖 Диплинки в боте (app/bot/handlers/start.py, shop.py)
- `/start buy_<id товара>` — сразу создаёт заказ и показывает реквизиты (новая функция send_purchase_offer в shop.py).
- `/start shop` — открывает витрину, `/start tariffs` — тарифы, `/start ref` — реферальная ссылка.

## Как обновить
1. Распаковать архив поверх папки бота (.env НЕ трогать), перезапустить run_bot.bat.
2. Содержимое папки webapp/ залить на GitHub Pages (инструкция в webapp/README_MINIAPP.md), адрес вписать в .env: WEBAPP_URL=...
3. В BotFather → Bot Settings → Menu Button → указать тот же адрес.
4. Проверить: /app → открывается хаб; вкладка Магазин → Купить → бот выдаёт заказ с копейками.

⚠️ Цены и товары в аппе задаются в CONFIG внутри webapp/index.html — держите их в синхроне с app/bot/shop_catalog.py и тарифами бота.
⚠️ Картинки товаров для аппа: положите jpg/png в webapp/img/ и укажите img: 'img/файл.jpg' у товара в CONFIG (в боте картинки — по-прежнему /set_photo).
