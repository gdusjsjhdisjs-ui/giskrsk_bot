# v8 — Пакет без VPS: статистика, бэкапы, алерты, лист ожидания, аукционы

Всё работает на домашнем ПК — VPS не нужен.

## Новые функции

### 📊 /stats — статистика для админа (app/bot/handlers/stats.py)
Пользователи, согласия на рассылку, рефералы, выручка по выданным заказам,
заказы по статусам, состояние пула аккаунтов, лист ожидания.

### 💾 Автобэкап (app/services/backup_service.py)
Раз в сутки: zip со всеми JSON-хранилищами + базой + .env в папку backups/
(хранятся последние 14), свежий архив отправляется первому админу в Телеграм.
⚠️ В бэкапе есть .env с ключами — не пересылайте архив никому.

### 🚨 Алерты об ошибках (app/bot/setup.py)
Любая необработанная ошибка бота прилетает админам в Телеграм
(не чаще раза в 10 минут на тип ошибки, чтобы не спамить).

### 🔄 Кнопка «Продлить подписку» (app/services/reminder_service.py)
Во всех напоминаниях (за 3/1 день, после окончания, после пробного дня)
теперь есть кнопка — клиент сразу попадает в список тарифов.

### 📋 Лист ожидания (app/services/waitlist_store.py, waitlist.json)
Если пул аккаунтов пуст при выдаче подписки/пробного дня — клиент
автоматически попадает в лист ожидания. После /add_account бот сам
уведомляет всех ожидающих, что место появилось.

### 🏛 /torgi — аукционы torgi.gov.ru (app/bot/handlers/torgi.py)
<code>/torgi Емельяново</code> — 5 свежих извещений с ценой, сроком заявок и
ссылками. Используется публичный API портала — ключи не нужны.
⚠️ Проверьте команду после установки: формат ответа портала мог измениться;
при проблемах бот честно отвечает «сервис не отвечает».

### 👋 Онбординг (app/bot/handlers/start.py)
Новые пользователи при первом /start видят краткий гид по возможностям:
карта, пробный день, магазин, аукционы, рефералка.

## Как обновить
Распаковать архив поверх папки бота (.env НЕ трогать), перезапустить run_bot.bat.
Новых настроек в .env не требуется.

## Проверка после установки
1. /stats (от админа) — показывает сводку.
2. /torgi Емельяново — показывает извещения.
3. Через ~1 минуту после старта первому админу придёт бэкап-архив.
