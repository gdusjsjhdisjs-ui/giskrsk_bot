# 🗺 Мини-приложение «ГИС Красноярье» для Telegram

Карта открывается прямо внутри Telegram. Движок — MapLibre GL (WebGL,
векторные тайлы): большие файлы не тормозят и не пропадают при приближении
(в отличие от старой версии на Leaflet+SVG).

## Что внутри

- `index.html` — всё приложение одним файлом (настройки — блок `CONFIG` в начале скрипта)
- `data/demo.geojson` — демо-слой для проверки (потом замените на свои файлы)
- `../tools/optimize_geojson.py` — сжатие больших GeoJSON перед загрузкой

Возможности: поиск населённых пунктов, 4 подложки (светлая/тёмная/OSM/спутник),
включение слоёв и прозрачность, карточка зоны по клику, геолокация, тёмная тема
под тему Telegram, кнопка «Полный доступ» ведёт в бота.

## Шаг 1. Опубликовать на GitHub Pages (бесплатно, 5 минут)

1. Зарегистрируйтесь на github.com (если ещё нет аккаунта).
2. Создайте репозиторий: **New repository** → имя `giskrsk-map` → Public → Create.
3. **Add file → Upload files** → перетащите содержимое папки `webapp`
   (файл `index.html` и папку `data`) → Commit.
4. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → Save.
5. Через минуту-две карта будет доступна по адресу:
   `https://ВАШ_ЛОГИН.github.io/giskrsk-map/index.html`

Альтернативы: Netlify Drop (перетащил папку — получил ссылку), Cloudflare Pages, Vercel.

## Шаг 2. Подключить к боту

1. В файл `.env` добавьте строку:
   `WEBAPP_URL=https://ВАШ_ЛОГИН.github.io/giskrsk-map/index.html`
2. Перезапустите бота. Команда `/app` теперь открывает карту.
3. (Рекомендуется) Сделайте кнопку карты возле поля ввода у всех пользователей:
   в @BotFather → /mybots → ваш бот → **Bot Settings → Menu Button** → укажите тот же URL.

## Шаг 3. Подключить свои слои

Откройте `index.html`, найдите блок `CONFIG` в начале скрипта. Три типа слоёв:

### А. Свой GeoJSON-файл (самый простой и быстрый)

Положите файл в папку `data/` и добавьте в CONFIG.layers:

    { id: 'pzz', name: 'ПЗЗ Емельяновский', type: 'geojson', url: 'data/pzz_emel.geojson', zoneProp: 'zone', visible: true }

`zoneProp` — имя свойства с кодом зоны (Ж-1, О-1…) — по нему раскрашивается карта.

**Важно:** большие файлы сначала прогоните через оптимизатор (шаг 4) —
обычно файл худеет в 3–10 раз.

### Б. Вектор прямо из NextGIS Web (файлы вообще не нужны)

    { id: 'ngw1', name: 'ПЗЗ (NextGIS)', type: 'ngw-vector', resource: 123, zoneProp: 'zone', visible: true }

`resource` — число из адреса ресурса: `…nextgis.com/resource/123`.
Слой должен быть доступен гостю: в NextGIS Web откройте ресурс →
**Управление доступом** → добавьте «Гость» с правом чтения. Если слой не
появился — добавьте в настройку `sourceLayer: 'имя_слоя'` (уточните у меня).

⚠ Так вы открываете данные бесплатно всем — подходит для демо-слоя-завлекаловки
(например, один район), а полный набор — только по подписке в NextGIS.

### В. Готовая картинка из NextGIS (стиль уже настроен там)

    { id: 'ngw2', name: 'Слой NextGIS', type: 'ngw-raster', resource: 456, visible: true }

`resource` здесь — id СТИЛЯ слоя (дочерний ресурс векторного слоя). Тоже нужно право чтения гостю.

## Шаг 4. Оптимизация больших GeoJSON (чтобы не тормозило)

    python tools/optimize_geojson.py большой.geojson data/pzz_emel.geojson --precision 6 --simplify 0.00003 --keep zone,zone_name,vri

Или без командной строки: загрузите файл на **mapshaper.org** → кнопка Simplify →
ползунок до 10–15% → Export → GeoJSON.

Почему теперь не лагает: MapLibre рисует через WebGL (видеокарту, как игры),
а GeoJSON сам нарезается на тайлы по уровням зума — на экран попадает только
видимая часть в нужной детализации. При приближении ничего не пропадает.
