# 🗺 ГИС Красноярье — Telegram-бот (@giskrsk_bot)

**Версия: 12 PRO** · Главный файл описания проекта

Бот-сервис для работы с градостроительными данными Красноярска и пригородов:
проверка участков по ПЗЗ, AI-анализ ограничений, продажа геоданных и подписок
на веб-карту (NextGIS Web).

---

## 💡 Что умеет бот

| Функция | Как работает |
|---|---|
| 🔍 **Проверка участка** | Кадастровый номер или точка на карте → зона ПЗЗ, разрешённое использование, ограничения |
| 🤖 **AI-консультант** | DeepSeek через OpenAI-совместимый API объясняет ПЗЗ человеческим языком |
| 📄 **PDF-отчёты** | Отчёт по участку (WeasyPrint + Jinja2) |
| 🗺 **Мини-приложение** | Карта внутри Telegram (webapp/index.html): слои, выбор области, заказ вырезки |
| ✂️ **Клип геоданных** | Пользователь рисует область → бот считает цену (max(990₽, км²×200₽, цена_слоя×2)) и режет GeoJSON по bbox |
| 🛒 **Магазин** | Готовые наборы ПЗЗ: Емельяновский/Дивногорск/Сосновоборск (3000₽), Красноярск GPKG (5000₽), проект QGIS (10000₽) |
| 💳 **Подписки** | Доступ к веб-карте: basic 30д=2990₽, pro 30д=4990₽, pro 90д=9900₽, год=24900₽. Оплата переводом на карту (копейки = код платежа) или ЮKassa |
| 👥 **Пул аккаунтов NextGIS** | Автовыдача логинов к карте после оплаты, лист ожидания |
| 🔔 **Мониторинг** | Отслеживание изменений слоёв, торги (torgi.gov.ru), напоминания о подписке |
| 📊 **Лимиты** | free=3, basic=30, pro=100 запросов/день (Redis) |

## ⌨ Основные команды

- `/start` — главное меню · `/help` — справка
- `/tariffs` — подписки · `/myorders` — мои заказы
- `/get_access` — получить логин к карте · `/my_account` — мой аккаунт
- Админу: `/add_account логин пароль` (с проверкой в NextGIS), `/accounts`, `/stats`

## 🏗 Архитектура (кратко)

```
app/
├── main.py            ← точка входа: python -m app.main
├── core/              ← config.py (все настройки из .env), enums, exceptions
├── bot/               ← aiogram 3: handlers/ (19 модулей), middlewares/, keyboards
├── db/                ← SQLAlchemy: models, session (PostgreSQL или SQLite)
├── services/          ← бизнес-логика: участки, AI, PDF, магазин, клип, пул аккаунтов
├── repositories/      ← доступ к БД
├── integrations/      ← NextGIS, YooKassa, Redis, Telegram, геосервисы
├── api/               ← FastAPI: /health, вебхуки ЮKassa, админ-API
└── workers/           ← фоновые задачи (мониторинг, напоминания)
webapp/index.html      ← мини-приложение (карта Leaflet + заказ клипа)
tools/                 ← clip_geodata.py (вырезка), optimize_geojson.py
shop_files/            ← товары магазина · clip_files/ ← готовые вырезки
alembic/               ← миграции БД
```

Стек: **Python 3.11+ · aiogram 3 · FastAPI · SQLAlchemy 2 · PostgreSQL/SQLite · Redis · NextGIS Web · DeepSeek AI · Shapely · WeasyPrint**

Подробнее: `ARCHITECTURE.md` (техническая архитектура) и `PROJECT_OVERVIEW.md` (полное описание).

## 🚀 Запуск

Подробная пошаговая инструкция — в **README_ZAPUSK.md**. Коротко:

1. Распаковать архив **с сохранением папок** (ПКМ → «Извлечь всё…»).
2. Скопировать `.env.example` → `.env`, заполнить токены.
3. **Вариант А (Docker):** `docker compose up -d --build` — всё поднимется само.
4. **Вариант Б (Windows):** двойной клик по `start.bat` — скрипт сам создаст venv, поставит зависимости и запустит бота. Для быстрого теста без PostgreSQL: `USE_SQLITE=true` в `.env`.

## 🔒 Безопасность

- Файл `.env` с реальными токенами НИКОМУ не передавать и не выкладывать.
- ❗ Текущие BOT_TOKEN и DEEPSEEK_API_KEY были засвечены — перевыпустите их (@BotFather / ЛК DeepSeek) перед боевым запуском.

1. **Redis больше не обязателен для локального запуска** — если Redis недоступен, кэш и дневные лимиты автоматически работают в памяти процесса. Для продакшена Redis по-прежнему рекомендуется (в Docker поднимается сам).
2. **Новый стиль мини-приложения** — премиум-тема: градиентные кнопки, «стеклянные» карточки с размытием, глубокая тёмная тема, анимации переходов между вкладками.
3. **Линейка на карте (📏)** — измерение расстояний по точкам + показ координат последней точки.
4. **Меню команд Telegram** — /start, /cancel и новая /help видны в кнопке «/» у поля ввода.
5. **Команда /help** — краткая справка по всем разделам бота.
